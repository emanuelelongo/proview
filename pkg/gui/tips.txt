# Status bar tips: less obvious gestures and behavior, one English tip per line.

Tip: Shift-click New page to create an image from your clipboard.
Tip: Hold Space and drag to pan a zoomed document or an STL model.
Tip: Ctrl-scroll (Cmd on macOS) zooms around the mouse pointer.
Tip: Hold Shift to select annotations without leaving the drawing tool.
Tip: Double-click added text to edit it directly on the page.
Tip: Ctrl/Cmd-click PDF thumbnails to pick pages; Shift-click selects a range.
Tip: Drag a selected PDF thumbnail to move the whole page selection.
Tip: Right-click selected PDF pages to duplicate or delete them together.
Tip: Select sidebar items, then right-click to create one PDF in sidebar order.
Tip: Alt-drag over PDF/image text to select pixels instead of words.
Tip: Markdown's list-tree icon opens a floating index; click the page to close it.
Tip: View > Markdown Theme changes the paper while keeping the workspace unchanged.
Tip: Ctrl/Cmd+C copies selected Markdown text, or the full source without a selection.
Tip: Right-click a Mermaid diagram to copy its PNG; its top button copies the code.
Tip: Click a QR code, then click its status-bar link to open it.
Tip: In Find, Enter goes to the next match; Shift+Enter goes back.
Tip: Find also searches image text when text recognition is enabled.
Tip: Missing required PDF fields do not prevent saving an unfinished draft.
Tip: Edit PDF Text: clear a word's value and click Apply to delete it.
Tip: Edit PDF Text: Duplicate starts dragging a copy; Move can be used repeatedly.
Tip: Hold Shift while moving PDF text to bypass snapping.
Tip: Right-click overlapping objects to change their front-to-back order.
Tip: Added PDF text, drawings and shapes stay editable after reopening.
Tip: Crop a PDF page to open the selected area as a separate image document.
Tip: In STL views, keys 1-7 select standard views; 0 toggles wireframe.
