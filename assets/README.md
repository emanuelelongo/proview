# Application icon

`app-icon.png` is the 1024 × 1024 PNG source for Proview's application icon.
The selected Arcade design combines a white document and magnifying glass with
violet, blue and cyan gradients inspired by the 1980s.
It was generated using the built-in image generation tool and resized with
macOS `sips`, preserving transparency. The macOS packaging task creates the
`.icns` resource; `FyneApp.toml` points to the PNG for Fyne packaging.
The PNG is also embedded in the executable and set as Fyne's application icon,
independently of the current working directory.

## Generation prompt

Edit this Proview app icon ONLY by recoloring. Preserve exactly all shapes, composition, scale, document and magnifying glass placement, rounded-square tile and margins, soft gradients, lens reflection and transparent outside background. Variant B: bright 1980s arcade palette, distinctly lighter than a dark indigo variant. Tile smooth gradient from vivid violet at the top through periwinkle to luminous sky blue/cyan at the bottom. Magnifying glass rim and handle medium violet with blue highlights, no dark navy or black. Lens pale aqua with a lavender reflection. White document with slight cool lavender folded corner. Colors remain predominantly purple and blue, with restrained cyan accents; no pink. Simple stylized design, no new objects or decoration, no neon glow outside edges, no grids, no stars, no text or watermark. One complete square icon. Preserve actual alpha transparency.
