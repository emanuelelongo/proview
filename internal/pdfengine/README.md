# Native PDF redaction

`RedactAndSanitize` removes selected content and rewrites a fresh PDF.
`TrialRedact` remains an unsafe comparison helper; application exports must
never use it. CGO and go-fitz's bundled native archives are required.

## Checks

```sh
task redact:probe
# Equivalent (also included in go test ./...):
go test -count=1 -v ./internal/pdfengine
```

The synthetic corpus checks native text, partial ActualText spans, Form XObjects,
embedded TrueType fonts and ligatures, existing OCR, shared/clipped scans,
rotations, offset CropBox/UserUnit, ancillary data, incremental revision removal,
preserved public pixels/vectors and explicit rejection of unsupported structures.
`pdfcpu` independently parses/decompresses output objects and inspects pixels;
MuPDF independently opens the exported bytes for text extraction/rendering.
Document and GUI tests cover overlay composition, snapshots, history, page edits,
live gestures, delayed geometry, save barriers and destination preservation.

Local runtime verification: macOS arm64. A three-page comparison document was
also opened, text-extracted and rendered with Apple's PDFKit. Selected native
text/alternative text/OCR were absent; extracted copies of the shared scan had
black pixels in the selected area and preserved their public footer. The eight
fixture markers were absent from decoded objects and attachments were removed.
Generated comparison artifacts are ignored under `build/redaction-preview/`.
Linux/Windows runtime checks run in CI; local success does not certify them.

## Export pipeline

1. Extract visible glyph quadrilaterals in normalized CropBox coordinates,
   ignoring alternative representations. Selection snaps to words and lines.
2. Bake visible widget/annotation appearances and reject unsupported structures.
3. Parse and re-emit content without marked-content properties. Remove ancillary
   keys from retained resources, including image metadata and alternative text.
4. Accumulate selected pixels per shared image object, then replace that image
   in every occurrence across the document, including clipped reuses. Original
   image resolution is retained; affected images are converted to RGB and the
   conservative pixel bounds are blacked out. Other image pixels are preserved.
5. Apply native Redact annotations: remove text, touched vector paths and selected
   image pixels; paint fixed opaque black bands. All app overlays are included
   before removal, regardless of their insertion order.
6. Graft page content/resources/boxes/rotation/transparency groups into a new PDF.
   Drop the original catalog, metadata, attachments, actions, field dictionaries,
   comments and structure tree. Write nonincrementally with garbage collection.
7. Validate the final bytes with pdfcpu before atomically saving locally.

`RedactComposedPDF` first validates every original source strictly, then permits
flattening the optional layer wrappers introduced by Proview's overlay writer.
This entry point is only for internally composed pages and app overlays. An
original PDF with hidden/optional layers is rejected even when overlays are added.

The source bytes remain unchanged. Each native call owns its context; exceptions
are caught in C and native allocations are released before returning to Go.
Undo remains available after Save. The GUI warns that export removes data and
that shared image changes affect other occurrences. Per-destination footprints
are kept outside Undo to warn before an overwrite could restore removed content.
PDF Save As selects a path before opening a writer, so cancelling confirmations
or failing export cannot truncate an existing destination.

## Supported scope and explicit errors

Text selection supports native PDF text and existing OCR. Starting a drag outside
selectable text creates an area rectangle, including on scans without OCR. The
gesture stays in its initial mode when crossing text and is clipped to the page.
It does not perform OCR or select Proview's added text as native text. Remove
and reselect marks to change their area. This is area removal plus ancillary data
sanitation, not a claim of forensic removal from the original disk, backups or
other source files. Information independently written elsewhere in the document
must also be selected. Touching a vector path may remove the entire path.

Unsupported structures produce an error and no export bytes:

- Encrypted input, optional/hidden layers and XFA forms.
- Type 3 fonts, tiling patterns, image stencils and inherited Form resources.
- Inline images; overlapping images with soft/color/stencil masks.
- Invalid regions/page indices or excessively nested resource dictionaries.

Vector-only appearances generated by MuPDF can have an empty Resources
dictionary; these are normalized without accepting inherited source Forms.
There is no black-box-only or full-page-raster fallback. Extend the corpus before
relaxing any rejection or changing native dependencies.
